# A01 - Broken Access Control

## Comment on a sécurisé l'accès à l'API

### Le problème

Sans contrôle d'accès, n'importe qui peut faire n'importe quoi sur l'API. Il faut s'assurer que :

- Seuls les utilisateurs connectés peuvent accéder aux données
- Chaque utilisateur ne peut faire que ce qui correspond à son rôle
- Personne ne peut modifier les données des autres

### Notre solution

#### 1. Authentification par JWT

Fichier : `src/middlewares/auth.js`

On utilise des tokens JWT pour vérifier qui est connecté. Le middleware `authenticateToken` :

- Récupère le token dans l'header Authorization
- Vérifie que le token est valide
- Charge les infos de l'utilisateur (rôle, association)
- Met tout ça dans `req.user` pour les autres middlewares

#### 2. Système de rôles

On a 3 rôles dans l'app :

**foster** (famille d'accueil)

- Peut créer des demandes d'adoption
- Peut voir ses propres demandes
- Peut rejoindre une association

**association**

- Peut gérer les animaux de son association
- Peut répondre aux demandes pour ses animaux
- Peut modifier les infos de son association

**admin**

- Peut tout faire (supprimer des users, etc.)
- Mais ne peut pas supprimer d'autres admins

#### 3. Protection des routes

Dans les fichiers de routes, on combine les middlewares :

```javascript
// Routes admin seulement
router.use(authenticateToken, requireRole("admin"));

// Créer un animal (association seulement)
router.post("/", authenticateToken, requireRole("association"), createAnimal);

// Faire une demande (famille seulement)
router.post("/", authenticateToken, requireRole("foster"), createRequest);
```

#### 4. Vérifications dans les contrôleurs

En plus des middlewares, on vérifie dans les contrôleurs que l'utilisateur peut vraiment faire l'action.

Par exemple, pour modifier un animal :

```javascript
// On vérifie que l'animal appartient à l'association de l'user
if (animal.id_association !== req.user.id_association) {
  return res.status(403).json({
    message: "Tu peux pas modifier les animaux des autres !",
  });
}
```

### Ce qu'on protège concrètement

- **Routes publiques** : liste des animaux, détails animal, liste associations
- **Routes connectées** : profil, création association, rejoindre association
- **Routes famille** : créer demande, voir mes demandes
- **Routes association** : CRUD animaux, voir demandes reçues, modifier statut demandes
- **Routes admin** : supprimer users, supprimer animaux

### Gestion des erreurs

- **401** : pas de token ou token invalide
- **403** : connecté mais pas les droits
- **404** : ressource existe pas
