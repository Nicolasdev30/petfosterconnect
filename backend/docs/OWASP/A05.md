# A05 - Security Misconfiguration

## Description

Les configurations de sécurité incorrectes représentent l'une des vulnérabilités les plus courantes dans les applications web. Cette catégorie inclut les configurations par défaut non sécurisées, les en-têtes de sécurité manquants, et l'exposition d'informations sensibles.

## Risques Identifiés

- **Exposition d'informations sensibles** : Stack traces, messages d'erreur détaillés
- **En-têtes de sécurité manquants** : CSP, HSTS, X-Frame-Options, etc.
- **Configurations par défaut** : Ports, comptes administrateur, mots de passe
- **Services non nécessaires** : Fonctionnalités activées par défaut
- **Gestion des erreurs** : Exposition de détails techniques

## Mesures Implémentées

### 1. En-têtes de Sécurité (Helmet.js)

```javascript
// Configuration helmet pour les en-têtes de sécurité
app.use(
  helmet({
    contentSecurityPolicy: {
      directives: {
        defaultSrc: ["'self'"],
        styleSrc: ["'self'", "'unsafe-inline'"],
        scriptSrc: ["'self'"],
        imgSrc: ["'self'", "data:", "https:"],
        // ... autres directives CSP
      },
    },
    hsts: {
      maxAge: 31536000,
      includeSubDomains: true,
    },
  })
);
```

**En-têtes appliqués :**

- `Content-Security-Policy` : Protection contre XSS et injection de contenu
- `Strict-Transport-Security` : Force HTTPS pendant 1 an
- `X-Content-Type-Options: nosniff` : Prévient le MIME sniffing
- `X-Frame-Options: SAMEORIGIN` : Protection contre clickjacking
- `X-XSS-Protection: 0` : Désactive le filtre XSS obsolète
- `Referrer-Policy: no-referrer` : Contrôle des informations de référence

### 2. Configuration CORS Sécurisée

```javascript
app.use(
  cors({
    origin: process.env.FRONTEND_URL || "http://localhost:5173",
    credentials: true,
    methods: ["GET", "POST", "PUT", "DELETE", "PATCH"],
    allowedHeaders: ["Content-Type", "Authorization"],
    optionsSuccessStatus: 200,
  })
);
```

### 3. Limitation des Requêtes

```javascript
// Limite la taille des requêtes à 10MB
app.use(express.json({ limit: "10mb" }));
app.use(express.urlencoded({ extended: true, limit: "10mb" }));
```

### 4. Validation de l'Environnement de Production

```javascript
// Vérification du JWT_SECRET en production
if (process.env.NODE_ENV === "production" && !process.env.JWT_SECRET) {
  console.error("❌ JWT_SECRET doit être défini en production");
  process.exit(1);
}
```

### 5. Gestion Centralisée des Erreurs

```javascript
// Middleware de gestion d'erreurs
const errorHandler = (err, req, res, next) => {
  const isDevelopment = process.env.NODE_ENV === "development";

  res.status(err.status || 500).json({
    message: err.message || "Erreur interne du serveur",
    ...(isDevelopment && { stack: err.stack }),
  });
};
```
