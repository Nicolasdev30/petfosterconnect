# 🎨 Charte Graphique de Pet Foster Connect

## 📄 Contexte

Pet Foster Connect est une application web permettant de mettre en relation des associations de protection animale et des familles d’accueil d’animaux. Le design doit inspirer confiance, chaleur, empathie, clarté et accessibilité. L’interface vise un style doux, rassurant et moderne, adapté à un public senior et au grand public.

## 🖊️ Typographies

| Usage         | Police                     | Remarques                     |
| ------------- | -------------------------- | ----------------------------- |
| Titres        | Poppins SemiBold ou Nunito | Moderne et friendly           |
| Texte courant | Inter Regular              | Lisibilité optimale           |
| UI / Légendes | Inter Medium / Poppins     | Bonne lecture sur petit écran |

Toutes les polices sont disponibles sur [Google Fonts](https://fonts.google.com).

---

## 📏 Grille & espacement (pour Figma)

- Grille 12 colonnes (desktop)
- Grille 4 ou 6 colonnes (mobile)
- Espacement standard : `16px` (mobile) / `24px` (desktop)
- Unités de base : `8px` (8, 16, 24, 32, ...)

## 🖼️ Illustrations

- Style flat design doux
- Formes rondes, personnages bienveillants, animaux stylisés
- Utiliser les couleurs principales de la palette
- Ombres subtiles pour profondeur

## 🗺 Pages & navigation

| Page                    | Style                              |
| ----------------------- | ---------------------------------- |
| Accueil                 | Hero visuel + slogan + CTA         |
| Connexion / Inscription | Cartes centrées, fond clair        |
| Liste animaux           | Grille ou colonne, cartes          |
| Détail animal           | Image à gauche, infos à droite     |
| Associations            | Grille, cartes logo + infos        |
| Dashboard               | Sidebar gauche, stats, cartes info |
| Admin                   | Sobriété, UI efficace              |

---

## 🚬 Accessibilité

- Couleurs conformes WCAG 2.1 niveau AA
- Texte min : `16px`
- Labels au-dessus des inputs
- Navigation clavier fluide, focus visibles
- États visibles : hover, focus, active
