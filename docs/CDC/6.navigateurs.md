# 🌍 Navigateurs Compatibles — Pet Foster Connect

L’application a été pensée pour être **responsive, accessible et performante** sur les principaux navigateurs modernes.

## ✅ Navigateurs testés et supportés

| Navigateur         | Version minimale recommandée | Observations                                    |
| ------------------ | ---------------------------- | ----------------------------------------------- |
| Google Chrome      | v100+                        | Testé desktop + mobile, aucune anomalie         |
| Mozilla Firefox    | v100+                        | Conforme au rendu prévu                         |
| Microsoft Edge     | v100+                        | Basé sur Chromium, parfaitement supporté        |
| Safari (macOS/iOS) | v15+                         | Attention aux flexbox sur vieilles versions iOS |
| Brave / Opera      | v100+                        | Fonctionne parfaitement (base Chromium)         |

## 📱 Mobile First & Responsive

- L’interface est conçue **en priorité pour les petits écrans** (smartphones), puis adaptée aux écrans plus larges (tablettes, desktop).
- Utilisation de **Tailwind CSS** pour des media queries efficaces et un design modulaire.

## ♿ Accessibilité

- L’accessibilité suit les recommandations du **RGAA (Référentiel Général d’Amélioration de l’Accessibilité)** niveau AA.
- Prises en compte : contraste des couleurs, navigation clavier, balises ARIA, éléments focusables.
- Tests manuels via lecteurs d’écran et outils comme **axe DevTools**.
