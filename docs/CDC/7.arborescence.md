# 🧭 Arborescence de l'application — Pet Foster Connect

Cette arborescence représente les routes accessibles par l'utilisateur dans l’interface frontend (SPA React Router). Elle correspond à l’organisation logique de la navigation et au parcours utilisateur.

## 🌐 Arborescence des routes frontend

├── /register → Page d’inscription (choix : association ou famille)
├── /login → Page de connexion
│└─── /dashboard → Tableau de bord utilisateur
│  ├── /dashboard/profile → Mon profil
│  ├── /dashboard/animals → Gestion des animaux (asso uniquement)
│  └── /dashboard/requests → Suivi des demandes (famille / asso)
│
├── /animals → Liste des animaux disponibles
│ └── /animals/:id → Fiche détaillée d’un animal
│
├── /associations → Liste des associations
│ └── /associations/:id → Fiche d’une association
│
└──  → Page 404 - non trouvé

## 🔐 Gestion de l’accès

Route | Accès | Description

/ | Public | Accueil avec présentation du projet
/login | Public | Connexion
/register | Public | Inscription (choix famille/asso)
/animals | Public | Liste des animaux filtrés
/animals/:id | Public | Fiche d’un animal
/associations | Public | Liste des associations
/associations/:id | Public | Fiche d’une association
/dashboard | Authentifié | Accès restreint à l’espace personnel
/dashboard/profile | Authentifié | Voir/éditer son profil
/dashboard/animals | Asso uniquement | Gérer les animaux à placer
/dashboard/requests | Tous connectés | Suivre ou traiter les demandes d’accueil

| Public | Page 404

Ressouces utiles:

- code uml schéma aborescence front end:
  
  @startuml
